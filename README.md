# NHL Dashboard

A dynamic web application to explore NHL player and team statistics.

---

## Features

- View league standings and conference rankings.
- Browse detailed team stats including player rosters.
- Select teams and players with dynamic filters.
- Visualize player stats.
- Separate views for skaters and goalies.
